Identifies a row

settlement_date
GB settlement date, as Elexon labels it
settlement_period
Half-hour of the day, 1 to 48; 46 or 50 on clock-change days
published_at
Vendor record time; each new version adds a row

Other columns

timestamp_utc
Start of the half-hour, computed from settlement date and period
system_sell_price
System sell price (SSP), £/MWh, as sent
system_buy_price
System buy price (SBP), £/MWh, from its own API field
net_imbalance_volume
Net imbalance, MWh; positive means the system was short, negative long
run_type
Settlement run; null, because this endpoint sends no run field
price_derivation_code
Elexon’s code for how the price was derived, as sent
