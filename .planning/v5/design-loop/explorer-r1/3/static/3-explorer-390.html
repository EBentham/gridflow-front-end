A React app over gridflow’s data

gridflow explorer is a web app for browsing everything gridflow collects: GB and European energy-market data from eight public sources, plus the tables gridflow builds from them.

It isn’t hosted, so the screens below are screenshots taken by its own screenshot tool.

gridflow-explorer on GitHub

Tap a screen to open it at full size.

React front end

React 19, TypeScript, Vite, Recharts and React Router.

No component kit or CSS framework: its own design tokens, light and dark, and one shared chart theme.

FastAPI backend

Python, FastAPI on uvicorn, and Polars.

It serves the source manifest, a dataset’s rows and coverage, forecast runs from the gold forecast store, and a job that runs gridflow’s ingestion to fill a missing range.

GridflowClient and DuckDB, read-only

It reads gridflow only through gridflow’s own client, never raw file paths, with DuckDB opened read-only per request.

The only thing it writes is gridflow’s catalogue, when it asks gridflow to fill a gap.

gridflow silver

GB and European energy-market data from eight public sources: Elexon BMRS, ENTSO-E, NESO Carbon Intensity, NESO Data Portal, ENTSO-G, GIE AGSI+, GIE ALSI and Open-Meteo.

The tables gridflow builds from them, and its forecast store.
