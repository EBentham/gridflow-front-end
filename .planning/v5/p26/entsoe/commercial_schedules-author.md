## Look hardest at (seat items first)

1. **Silent loss of the day-ahead schedule (gridflow defect, seat item).**
   - With no `contract_MarketAgreement.Type` filter, each reply for seven of the eight pairs carries two TimeSeries: `A01`, then `A05`.
   - They share `businessType` `A06` and every timestamp.
   - The parser has no branch for the tag `contract_MarketAgreement.type`. It matches only `Type_MarketAgreement.Type` and similar (`parsers.py:320-328`), so `market_agreement_type` is empty.
   - The transformer does not output it, and its dedup is `unique(subset=[timestamp_utc, in_area_code, out_area_code, business_type], keep="last")` (`h6_market.py:91-98`).
   - So silver holds whichever series the reply lists last. The day-ahead series is discarded, and the outcome depends on vendor element order, not on any code rule.
   - The page states this as a project check.
2. **`A05` means "total": only third-party evidence.**
   - The open-source entsoe-py client requests `A05` when `dayahead=False` and `A01` when `dayahead=True`.
   - The vault records `A01` as "daily" on other ENTSO-E notes. No ENTSO-E quote for `A05` is in the repo or vault.
   - I tried two sources. The ENTSO-E guide HTML returned HTTP 400. The Postman documentation renders client-side, so nothing could be read.
   - The page says "total in the entsoe-py client's reading". Needs a vendor quote (research item).
3. **Direction is a project check, not a vendor quote.**
   - Rows with `in_area_code` GB correlate with the import part of Elexon FUELHH interconnector flows: FR (INTFR+INTIFA2+INTELEC) 0.92, BE (INTNEM) 0.86, NL (INTNED) 0.94, IE-SEM (INTEW+INTIRL+INTGRNL) 0.85.
   - They correlate negatively with the export part.
   - entsoe-py's `_query_crossborder` sets `in_Domain` to the "to" zone, which agrees.
   - The sister page reached the same reading for A11.
4. **"Tracks" in the France and Belgium key notes is loose.**
   - There were 112 (FR) and 122 (BE) hours in the local range with a scheduled import above 50 MW while Elexon showed net export above 100 MW.
   - That fits gross one-way schedules with the reverse direction not fetched. It is not verified, because the reverse is never requested.
   - The checker may want softer wording.
