Aggregated balancing services adjustment data

neso_data_portal/aggregated_bsad

NESO's net adjustments for balancing actions outside the Balancing Mechanism, per settlement period: cost, volume and a buy and sell price adjuster.

Vendor
NESO Data Portal, package aggregated-bsad: one CSV file per financial year
Cadence
Updated twice daily, as NESO's package text states
Grain
One row per settlement period and capture; the latest view keeps one
Key
resource_id, settlement_date, settlement_period
History
NESO lists files from 2013-14, none for 2015-16; gridflow loads 2016-17 on, except 2020-21

What it is

BSAD is how NESO submits balancing actions taken outside the Balancing Mechanism to the BSC, whose rules govern imbalance settlement (NESO). This package nets them per settlement period, with no individual action. The six cost and volume terms are zero in every row shown; the buy price adjuster bpa is the one charted.

How it’s used

  • NESO's buy price adjuster per settlement period, for imbalance price studies.
  • Flagging settlement periods with a non-zero adjuster, as a feature beside imbalance prices.
  • Setting NESO's files beside Elexon's NETBSAD, whose eight terms carry similar names.

Identifies a row

settlement_date
GB settlement date, as NESO labels it, on the UK local clock (NESO)
settlement_period
Half-hour of the settlement day, 1 to 48; 46 or 50 on clock-change days
resource_id
CKAN id of the financial-year file the row came from

Other columns

bpa
Buy price adjuster, £/MWh (NESO); NESO does not state its sign convention
spa
Sell price adjuster, £/MWh (NESO); NESO does not state its sign convention
ebca
Energy buy cost adjustment, £ (NESO)
ebva
Energy buy volume adjustment, MWh (NESO)
sbva
System buy volume adjustment, MWh (NESO)
esca
Energy sell cost adjustment, £ (NESO)
esva
Energy sell volume adjustment, MWh (NESO)
ssva
System sell volume adjustment, MWh (NESO)
timestamp_utc
Start of the settlement period, UTC, computed from date and period
published_at
Null: gridflow takes no vendor publication time for this table
bronze_capture_id
Path of the bronze capture the row was read from
capture_written_at
When gridflow wrote that capture to bronze, UTC

Query it from a notebook

Returns a pandas DataFrame from the DuckDB view silver_neso_data_portal_aggregated_bsad_latest, every row of each file's newest capture, filtered on settlement_date with both ends included; lineage columns dropped.

Needs gridflow and gridflow-models installed, with a capture of NESO's yearly files from 2016-17 ingested.
